# Sana Sabih — Personal Portfolio

Final exam project built with plain **HTML, CSS and JavaScript** (no frameworks).

## Features
- Home, About, Skills, Projects, Education/Experience, Contact and Footer sections
- Dark / Light mode toggle (saved in localStorage)
- Fully responsive (mobile, tablet, desktop)
- LinkedIn, WhatsApp, Email and Download CV buttons

## Projects included
- `projects/clothing-brand/` — Coza Store (Mid-Term Exam Project)
- `projects/todo-app/` — To-Do Application

## Before deploying
1. Replace `images/profile.svg` with your photo and update the `src` in `index.html`
2. Update your LinkedIn URL and email address in `index.html` (search for `linkedin.com` and `mailto:`)
3. Update the GitHub link in the footer

## Deploy
Push this folder to GitHub, then enable **GitHub Pages** (Settings → Pages → Branch: main) or drag the folder onto **Netlify**.
